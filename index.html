F1 Race Visualization

This web visualization is a demo with pre-loaded race datasets. The main application is the Python app which fetches data via the FastF1 API and visualizes races that have happened. This page showcases the visualization using exported JSON and runs entirely on GitHub Pages (no backend needed).

Getting Started

Clone the repository and preview the static site locally:

bash
git clone https://github.com/Tausif-Rahman/F1-Race-Visualization.git
cd F1-Race-Visualization
python3 -m http.server 8000
# Open http://localhost:8000/

What It Does

This application loads historical F1 race data and creates an animated visualization showing:

  • Track Layout: A visual representation of the F1 circuit
  • Driver Positions: Real-time positions of all drivers on the track during the race
  • Race Dashboard: Live leaderboard showing driver positions, lap times, and gaps
  • Playback Controls: Play, pause, and adjust speed of the race replay

The visualization uses actual telemetry data from F1 races to accurately recreate driver positions lap-by-lap.

Requirements

For the web visualization (GitHub Pages): just a modern browser. No backend needed.

For exporting data / desktop app :

  • Python 3.12+
  • fastf1
  • arcade

Usage

Note: GitHub Pages is a static demo; Flask is for local API-backed viewing. Choose one of the three modes below.

Web (Static Demo): Preview locally.

bash
python3 -m http.server 8000
    # Open http://localhost:8000/

Desktop App (Arcade): Visualize races in a local desktop window.

bash
python3 run.py
    # OR
python3 -m src

The first run will download and cache race data. Subsequent runs will use the cached data.

Flask (Local API): Serve a webpage from your computer and view API-backed data.

  • Server: http://127.0.0.1:3000/
  • Homepage: Renders templates/index.html
  • API: /api/race/<year>/<round>/<num_laps>, /api/season/<year>, /api/health
bash
# (Optional) use a virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install project dependencies
pip install -r requirements.txt

# Start the local API + template server
python3 api.py

# Open the site and test endpoints

# Race API:    http://127.0.0.1:3000/api/race/2025/1/58

When running Flask, the homepage comes from the template in templates/index.html and data is fetched from the local endpoints in api.py. For GitHub Pages hosting, this index.html remains purely static.

How It Works

This site is fully static, designed for GitHub Pages:

  • Data Export: A Python exporter writes race telemetry + lap times to static/data/*.json.
  • Dataset Index: static/data/index.json lists available datasets and is auto-maintained.
  • Client Visualization: The browser loads JSON and animates drivers on a canvas with lap progression.
  • No Backend Required: All data is fetched as static files; no Flask needed in production.

Web Visualization

The front-end logic lives in static/js/viz.js:

  • Loading: Tries static/data/index.json; if missing, uses window.DATASET or a default file.
  • Track Rendering: Builds a scaled track from lap 1 telemetry and draws it with Canvas 2D.
  • Position Calculation: Aggregates lap times + current lap progress to compute race order.
  • Animation Loop: Advances progress and currentLap, updates the dashboard and markers.
  • Controls: Space (pause), Up/Down (speed). Responsive to window resizes.

Exporter & Commands

Use the exporter to generate static datasets from the FastF1 cache:

bash
# Export Australian GP (Round 1)
python3 -m src.export_static_json 2025 1

# Export additional rounds (examples)
python3 -m src.export_static_json 2025 2
python3 -m src.export_static_json 2025 3

# Start a local static server to preview
python3 -m http.server 8080
# Then open http://localhost:8080/

Outputs are written to static/data/ and the index file (index.json) is updated automatically.

Repository Overview

  • index.html: This page. Hosts the visualization and documentation.
  • static/js/viz.js: Canvas renderer and race animation, loads static JSON datasets.
  • static/data/: Pre-exported datasets and index.json list.
  • src/export_static_json.py: Exporter producing the static JSON from FastF1 cache.
  • cache/: FastF1 cache assets (timing, telemetry). Used by the exporter.
  • src/main.py & run.py: Desktop visualization using the Arcade engine.
  • api.py & templates/index.html: Dev-only Flask API + template

Data Source

Race data is provided by the FastF1 library, which accesses official timing data. Datasets are exported locally and served as static files for the web visualization.
